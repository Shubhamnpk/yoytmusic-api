How It Works

Serverless functions in api/ call ytmusicapi.

CORS is enabled so any browser app can call the endpoints.

Upgrade later with OAuth to access library, playlists, and uploads.

Built on top of ytmusicapi. HTTPS recommended. Auth can be added when needed.
