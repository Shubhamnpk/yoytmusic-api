# Contributing

Thank you for your interest in contributing to **yoytmusic-api**! 

Whether it's bug fixes, new features, or documentation improvements, we welcome all contributions.

## How to Contribute

1. **Fork the repo** and clone it locally.
2. **Install dependencies**: `pip install -r requirements.txt -r requirements-dev.txt`
3. **Run tests**: Make sure everything is green with `pytest`.
4. **Create a branch**: Use a descriptive name like `fix/search-error` or `feat/oauth-flow`.
5. **Make your changes** and add tests if appropriate.
6. **Lint and format**: Follow current codebase style (single quotes vs double quotes, standard indentation).
7. **Submit a Pull Request**: Provide a clear description of what you've done and why.

## Development Setup

- Use `python dev_server.py` to run locally and test with the `public/` landing page.
- Test your API endpoints with the provided OpenAPI spec at `http://localhost:3000/docs/openapi.json`.

## Code of Conduct

Please be respectful and helpful. We aim to keep this project friendly for everyone.
