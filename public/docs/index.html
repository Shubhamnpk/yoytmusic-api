Public + Auth

HTTP docs for the yoytmusic-api wrapper.

This API exposes public YouTube Music data through simple HTTP endpoints built on top of ytmusicapi. Public endpoints live under /api/public. Auth-required endpoints live under /api/auth and return 401 until OAuth is enabled.

Base URL: https://YOUR_APP.vercel.app

Endpoints

GET /api/health

{"ok": true}

GET /api/version

{"app_version":"0.1.0","ytmusicapi_version":"...","build_time":"..."}

Search

GET /api/public/search

Param Type Required Default Notes
q string Yes - Search query
limit int No 10 Clamped between 1 and 25
filter string No null songs, videos, albums, artists, playlists

Global Search

GET /api/public/global-search

Param Type Required Default Notes
q string Yes - Search query
limit int No 10 Clamped between 1 and 25
filters string No songs,artists,playlists Comma-separated list of: songs, videos, albums, artists, playlists

Generic Method

GET /api/public/ytmusic

Param Type Required Default Notes
method string Yes - Must be in allowlist
args JSON array No [] Positional args for the method
kwargs JSON object No {} Keyword args for the method

POST /api/public/ytmusic accepts the same fields in a JSON body.

/api/auth/ytmusic is reserved for OAuth-protected methods and returns 401 until enabled.

Legacy endpoints: /api/search and /api/ytmusic remain for backward compatibility.

Examples

Search request:

curl "https://YOUR_APP.vercel.app/api/public/search?q=Oasis&limit=5&filter=songs"

Get song details (POST):

{
  "method": "get_song",
  "args": ["VIDEO_ID"],
  "kwargs": {}
}

Generic method (GET):

/api/public/ytmusic?method=get_playlist&args=["PLAYLIST_ID"]

Error Format

{
  "error": "...",
  "detail": "...",
  "allowed_methods": ["..."]
}

Validation errors return HTTP 400. Server or upstream failures return HTTP 500.

Allowed Methods

search get_song get_album get_artist get_artist_albums

get_artist_singles get_artist_videos get_artist_playlists get_artist_related

get_playlist get_watch_playlist get_lyrics get_home get_explore

get_new_releases get_charts get_mood_categories get_mood_playlists

Notes

CORS is enabled with Access-Control-Allow-Origin: *.

Search results are clamped to a maximum of 25 items per request.

This API is read-only. Authenticated features require OAuth support.

Need auth or uploads? Add OAuth support and enable protected methods.
